## 🚀 Как использовать?

### Первая настройка (5 минут)

1. **Получить Service Role Key:**
   - Supabase → Settings → API
   - Скопировать Service Role Key (НЕ Anon Key!)

2. **Обновить admin-app.js:**
   ```javascript
   const SUPABASE_URL = 'https://YOUR_PROJECT.supabase.co';
   const SUPABASE_SERVICE_KEY = 'eyJ...';  // Service Role Key
   const CORRECT_PASSWORD = 'твой_пароль'; // Придумай пароль
   ```

3. **Git push:**
   ```bash
   git add admin.html admin-app.js admin-styles.css
   git commit -m "Add admin panel"
   git push
   ```

### Ежедневное использование

1. Открыть `https://username.github.io/diana-survey/admin.html`
2. Ввести пароль
3. Нажать нужную кнопку:
   - 📊 **Скачать Excel** — основной вариант для аналитиков
   - 📄 **Скачать CSV** — для импорта в системы
   - { } **Скачать JSON** — для программистов

## 📊 Функции админ-панели

### 1. Аутентификация

- Простой пароль (в localStorage на 1 час)
- Кнопка "Выйти" для разрыва сессии
- Защита от автоматического доступа

### 2. Статистика

**Три метрики в реальном времени:**
- **Всего ответов** — COUNT(*) из responses
- **Последний ответ** — MAX(created_at)
- **Средний ИМТ** — AVG(computed.bmi)

### 3. Фильтры

```
От даты: [________]  По дату: [________]  [Применить]
```

- Выбрать диапазон дат
- Таблица и статистика обновляются
- При экспорте скачивается отфильтрованные данные

### 4. Выгрузка (3 формата)

#### Excel (.xlsx) ⭐ РЕКОМЕНДУЕТСЯ

```
📊 Скачать Excel (.xlsx)
```

**Содержимое:**
- Все 17 столбцов (шифр, возраст, вес, рост, ИМТ, и т.д.)
- Красивый формат (заголовки жирные, колонки отрегулированы)
- Готово открыть в Excel / Google Sheets / LibreOffice
- **Размер:** ~50–100 KB за 1000 ответов

**Пример:**

| Шифр | Дата | Возраст | Вес | Рост | ИМТ | Недержание |
|------|------|---------|-----|------|-----|-----------|
| CODE001 | 31.01.2025 17:30 | 35 | 75 | 175 | 24.5 | 2 |
| CODE002 | 31.01.2025 17:45 | 42 | 80 | 170 | 27.7 | 5 |

#### CSV (.csv)

```
📄 Скачать CSV
```

- Универсальный текстовый формат (comma-separated values)
- Хорошо работает в Python, R, Tableau
- **Размер:** ~30–50 KB за 1000 ответов

#### JSON (.json)

```
{ } Скачать JSON
```

- Полная структура данных (включая вложенные JSON поля)
- Для API интеграции или программной обработки
- **Размер:** ~60–100 KB за 1000 ответов

### 5. Предпросмотр таблицы

- Первые 10 строк данных в браузере
- Быстрая проверка перед экспортом
- Горизонтальная прокрутка для больших таблиц
- Макс высота 500px (не грузит браузер)

## 🔒 Безопасность

### Почему это безопасно?

| Компонент | Защита |
|-----------|--------|
| **Service Role Key** | Только на админ-странице, не в основном приложении |
| **Пароль** | Хранится в localStorage на 1 час |
| **HTTPS** | GitHub Pages автоматически HTTPS |
| **Access Control** | Анонимные пользователи не могут получить доступ к админ-интерфейсу |

### Что видит админ?

✅ **Видит:**
- Все ответы пользователей (таблица responses)
- Дата отправки
- Вычисленные показатели (ИМТ)

❌ **НЕ видит:**
- Защита на RLS всё равно работает (если настроена правильно)
- Приватные ключи пользователей (нет таких)

### Что делать, если пароль украден?

1. Быстро изменить пароль в `admin-app.js`
2. Git push
3. GitHub Pages обновится (1-2 минуты)
4. Старый пароль больше не работает

## ⚙️ Конфигурация

### Пароль администратора

Файл: `admin-app.js`, строка:

```javascript
const CORRECT_PASSWORD = 'admin123'; // Измени на свой пароль!
```

**Как сделать безопаснее?**
- Используй длинный пароль (15+ символов)
- Не используй простые пароли типа "123", "password"
- Рекомендуемый формат: `Pr0j3ct!D1ana2025`

### Длительность сессии

Файл: `admin-app.js`, функция `validateSession`:

```javascript
const sessionExpiry = 1000 * 60 * 60; // 1 час
```

Текущее значение: **1 час**. Если нужно другое:
- 30 минут: `1000 * 60 * 30`
- 2 часа: `1000 * 60 * 60 * 2`
- 1 день: `1000 * 60 * 60 * 24`

## 🐛 Troubleshooting

### Проблема: "Ошибка 401" при загрузке данных

**Причина:** Service Role Key неправильно скопирован

**Решение:**
1. Проверить admin-app.js
2. Скопировать Service Role Key ещё раз (Settings → API)
3. Убедиться, что это именно **Service Role Key**, не Anon Key
4. Перезагрузить страницу (F5)

### Проблема: "Неверный пароль" при вводе правильного

**Причина:** Пробелы в пароле или опечатка

**Решение:**
1. Открыть F12 → Console
2. Вводить пароль медленнее, проверить спецсимволы
3. Изменить пароль в admin-app.js на более простой

### Проблема: Excel не скачивается

**Причина:** Браузер блокирует загрузку

**Решение:**
1. Проверить параметры браузера (Settings → Downloads)
2. Попробовать другой браузер
3. Очистить кэш (Ctrl+Shift+Del)

### Проблема: Таблица не загружается ("Нет данных для отображения")

**Причина:** 
- Нет ответов в Supabase, или
- RLS запретила SELECT

**Решение:**
1. Проверить: есть ли ответы в Supabase (Table UI → responses)
2. Проверить RLS политики (SELECT должна быть запрещена для anon, но разрешена для Service Key)
3. Посмотреть Network tab (F12) — какой статус возвращает Supabase?
