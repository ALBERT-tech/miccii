# АДМИНИСТРАТОРСКАЯ ПАНЕЛЬ — Руководство

## 📊 Быстрый старт

### 1. Где находится админ-панель?
```
https://your-domain.github.io/admin.html
```

### 2. Что нужно сделать перед первым использованием

#### Шаг 1: Получить Service Role Key из Supabase

1. Открыть https://app.supabase.com → ваш проект
2. Settings → API (левое меню)
3. Скопировать **Service Role Key** (НЕ Anon Key!)

#### Шаг 2: Обновить admin-app.js

Открыть файл `admin-app.js` и найти:

```javascript
const SUPABASE_URL = 'https://YOUR_PROJECT.supabase.co';
const SUPABASE_SERVICE_KEY = 'YOUR_SERVICE_ROLE_KEY';
const CORRECT_PASSWORD = 'admin123';
```

Заполнить реальные значения:

```javascript
const SUPABASE_URL = 'https://xyzabc.supabase.co';
const SUPABASE_SERVICE_KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...'; // Service Role Key
const CORRECT_PASSWORD = 'ТВОЙ_ПАРОЛЬ'; // Придумай свой пароль
```

⚠️ **ВАЖНО:** Service Role Key должен быть только на админ-странице. Никогда не публикуй его на GitHub вместе с основным кодом!

#### Шаг 3: Загрузить файлы на GitHub

```bash
git add admin.html admin-app.js admin-styles.css
git commit -m "Add admin panel for data export"
git push
```

### 3. Первый вход

1. Открыть `https://your-domain.github.io/admin.html`
2. Ввести пароль (который ты установил в `CORRECT_PASSWORD`)
3. Нажать "Войти"

## 🎯 Функции администраторской панели

### Статистика
- **Всего ответов** — общее количество заполненных опросников
- **Последний ответ** — когда был последний ответ
- **Средний ИМТ** — средний индекс массы тела по всем ответам

### Выгрузка данных (3 формата)

#### 1️⃣ Excel (.xlsx) — РЕКОМЕНДУЕТСЯ
- ✅ Удобный формат для анализа
- ✅ Все столбцы отформатированы
- ✅ Подходит для Excel / Google Sheets / LibreOffice
- Кнопка: **📊 Скачать Excel (.xlsx)**

**Содержит столбцы:**
- Шифр, Дата, Возраст, Роды, Вес, Рост, Окружность талии
- Дневные микции, Ночные микции, Жидкость, Моча
- Позывы, Недержание, Прокладки, Энурез
- ИМТ, Согласие

#### 2️⃣ CSV (.csv)
- Универсальный текстовый формат
- Хорошо работает в Python, R, другие BI инструменты
- Кнопка: **📄 Скачать CSV**

#### 3️⃣ JSON (.json)
- Полная структура данных с ответами на все вопросы
- Для программной обработки
- Кнопка: **{ } Скачать JSON**

### Фильтры

Можно выгружать данные за конкретный период:

1. Установить "От даты" (начало периода)
2. Установить "По дату" (конец периода)
3. Нажать "Применить фильтры"
4. Таблица и статистика обновятся
5. Нажать кнопку выгрузки — скачается отфильтрованные данные

**Пример:** Выгрузить ответы за январь 2025
- От даты: 01.01.2025
- По дату: 31.01.2025
- Результат: только ответы из января

### Предпросмотр таблицы

Показывает первые 10 строк:
- Шифр, Дата/время, Основные параметры, ИМТ, Недержание

Если ответов больше 10 — это не предпросмотр, полный файл скачивается при нажатии кнопки "Скачать".

## 🔒 Безопасность

### Аутентификация
- ✅ Простой пароль (можешь изменить)
- ✅ Сессия хранится в браузере (localStorage) на 1 час
- ⚠️ В продакшене — использовать более сложную аутентификацию (JWT, OAuth)

### Защита Service Role Key
- ✅ Используется только на админ-странице
- ✅ Никогда не передавайся в основное приложение
- ⚠️ Храни admin-app.js в приватном репозитории или переменных окружения

### Что видит админ?
- ✅ Все ответы пользователей (все данные таблицы responses)
- ✅ Дата отправки
- ❌ НЕ видит IP-адреса, браузеры, метаданные (лежат в client_meta)

## 📥 Примеры использования

### Использование 1: Еженедельный экспорт

**Каждый понедельник:**
1. Открыть админ-панель
2. Установить фильтры на предыдущую неделю
3. Нажать "Скачать Excel"

1. Скачать Excel файл
2. Открыть в Excel / Google Sheets
3. Добавить формулы:
   - `=AVERAGE(F:F)` — средний рост
   - `=AVERAGE(E:E)` — средний вес
   - `=COUNTIF(M:M,">5")` — сколько человек с недержанием > 5 раз

### Использование 3: Импорт в базу данных

1. Скачать CSV
2. Открыть в Python:

```python
import pandas as pd

df = pd.read_csv('responses_2025-01-31.csv')
print(df.describe())  # Статистика
print(df[['Возраст', 'ИМТ', 'Недержание']])  # Выбранные столбцы
```

### Использование 4: Резервная копия

1. Каждый месяц скачивать Excel
2. Архивировать на диск (или облако)
3. Безопасность: у тебя есть копии всех ответов

## ❓ Часто задаваемые вопросы

### Q: Забыл пароль. Что делать?
**A:** Редактировать `admin-app.js`, строка:
```javascript
const CORRECT_PASSWORD = 'новый_пароль';
```
Затем git push.

### Q: Есть пароль? Нужен ли Login/Pass с логином?
**A:** Для MVP пароля достаточно. Для продакшена добавить:
- GitHub OAuth
- Email + пароль (в БД)
- Two-factor authentication (2FA)

### Q: Может ли администратор редактировать/удалять ответы?
**A:** Нет, в MVP только чтение и выгрузка. Для редактирования нужно:
1. Добавить UPDATE политику в RLS
2. Создать интерфейс для редактирования
3. Логировать все изменения

### Q: Какой формат выбрать — Excel, CSV или JSON?
**A:** 
- **Excel** — для аналитиков, менеджеров (9/10 используют Excel)
- **CSV** — для программистов, импорта в БД
- **JSON** — для API интеграции с другими системами

### Q: Безопасно ли хранить Service Key на админ-странице?
**A:** 
- ✅ Если админ-страница приватна (под паролем) — да
- ✅ Если не публикуешь на публичном GitHub — да
- ❌ Если опубликуешь Key в публичном репо — УЯЗВИМОСТЬ!

### Q: Как ограничить доступ админа только к определённым данным?
**A:** Использовать RLS политики с условиями:
```sql
CREATE POLICY "admin_access" ON responses
  FOR SELECT
  USING (auth.uid() = 'admin_user_id');
```

### Q: Может быть несколько администраторов?
**A:** Да! Несколько способов:
1. Один пароль для всех (простой, но не безопасный)
2. Список паролей (в коде)
3. Отдельный логин для каждого (через Supabase auth)
